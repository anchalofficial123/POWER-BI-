# Power BI Project: Overview

## Description
This Power BI project demonstrates an interactive dashboard for insightful visualizations and analytics. It tracks KPIs and provides decision-making support.

## Features
- Interactive visualizations with filters.
- Integrated data from multiple sources.
- Tracking of key metrics and trends.

## Data Details
- **Columns:** 'SeniorCitizen', 'Churn', 'PhoneService', 'InternetService', etc.
- **Data Transformation:** Cleaned and modeled using Power Query.

## Visualizations
- Churn Analysis: Charts on customer churn trends.
- Service Usage: Graphs showing service usage patterns.
- Demographics: Visuals on customer demographics.

## Tools Used
- Power BI Desktop
- DAX Functions
- Power Query

## Usage
1. Open the .pbix file in Power BI Desktop.
2. Use slicers and filters for customized views.
